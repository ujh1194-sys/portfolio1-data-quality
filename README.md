
# 주문 데이터 품질 모니터링 프로젝트

## 프로젝트 개요

가상의 주문 데이터에서 NULL, 중복, 허용값 위반, 금액 오류, 날짜·시간 오류를 탐지하고,
운영 대응 우선순위와 후속 조치를 정의한 데이터 품질 모니터링 프로젝트입니다.

pandas를 이용해 데이터 품질 검사를 수행하고,
규칙별 오류율과 주요 KPI를 Tableau 대시보드로 시각화했습니다.

## 사용 기술

- Python
- pandas
- CSV
- Tableau
- Git / GitHub

## 주요 결과

총 124행의 가상 주문 데이터를 대상으로 9개의 데이터 품질 규칙을 검사했습니다.

- 전체 데이터: 124행
- 문제 행: 23행
- 문제 행 비율: 18.55%
- 우선 대응 행: 13행
- 확인 필요 행: 10행
- 전체 품질 규칙: 9개
- 실제 오류가 발생한 품질 규칙: 8개

규칙별 품질 검사 결과는 다음과 같습니다.

| 품질 규칙 | 오류 행 수 |
|---|---:|
| order_id 중복 | 8 |
| updated_at 시간 순서 위반 | 4 |
| customer_id NULL | 3 |
| status 허용값 위반 | 3 |
| amount 0 이하 | 2 |
| payment_method 허용값 위반 | 2 |
| 미래 order_date | 2 |
| amount NULL | 1 |
| order_id NULL | 0 |

하나의 행에서 여러 품질 규칙을 동시에 위반할 수 있으므로,
규칙별 오류 행 수의 합계와 전체 문제 행 수는 다를 수 있습니다.

문제 행 비율 18.55%는 전체 데이터 중 하나 이상의 품질 규칙을 위반한 행의 비율이며,
품질 개선율을 의미하지 않습니다.

각 오류 행에 위반 규칙, 위반 규칙 개수, 운영 대응 우선순위, 후속 조치를 연결하고,
규칙별 오류율과 전체 품질 KPI를 Tableau 대시보드로 시각화했습니다.

## 수행 내용

- pandas를 이용한 주문 데이터 품질 검사
- NULL, 중복, 허용값, 금액, 날짜·시간 규칙 검증
- 여러 품질 문제가 동시에 발생한 행의 오류 규칙 통합
- 조건별 오류 개수 누적 및 문제 행 추출
- 문제 유형에 따른 운영 대응 우선순위 및 후속 조치 정의
- 규칙별 오류 행 수와 오류율 계산
- Tableau 기반 데이터 품질 모니터링 대시보드 구성
- Quality Rule Catalog를 이용한 품질 규칙 문서화
- Control Matrix를 이용한 품질 규칙과 업무 위험 연결
- Data Lineage를 이용한 데이터 처리 흐름 문서화

## 데이터 품질 규칙

주문 데이터의 품질을 확인하기 위해 다음 품질 차원을 기준으로 규칙을 정의했습니다.

- 완전성: 필수 데이터의 NULL 여부 확인
- 유일성: order_id 중복 여부 확인
- 유효성: 상태 코드, 결제수단, 금액, 날짜 값이 허용 기준에 맞는지 확인
- 일관성: 주문 날짜와 갱신 시각의 논리적 순서 확인

전체 품질 규칙은 `quality_rule_catalog.csv`에서 관리합니다.

미래 주문 날짜 검사는 실습 데이터의 기준일인 2026-09-21을 기준으로 수행합니다.

## 운영 대응 우선순위

데이터 오류가 주문 건수, 매출 등의 주요 운영 지표에 미칠 수 있는 영향을 고려하여
문제 행의 대응 우선순위를 분류했습니다.

- 우선 대응: order_id 중복, amount NULL, amount 0 이하, 미래 order_date 중 하나 이상의 오류가 발생한 행
- 확인 필요: 그 외 품질 오류가 발생한 행

각 행에 발생한 품질 오류에 따라 필요한 후속 조치를 함께 기록했습니다.

기존 CSV 및 Tableau 대시보드와의 호환성을 위해 코드와 결과 파일에서는
`severity`라는 컬럼명을 유지하지만, 실제 분류 기준은 운영 대응 우선순위입니다.

## Control Matrix

데이터 품질 규칙을 업무 위험과 연결해 관리했습니다.

각 규칙에 대해 다음 항목을 확인했습니다.

- Risk: 데이터 오류로 인해 발생할 수 있는 업무 위험
- Control: 위험을 발견하기 위한 품질 검사
- Threshold: 허용 가능한 오류 기준
- Actual Result: 실제 탐지된 오류 행 수
- Status: 기준 충족 여부(PASS / FAIL)
- Action: 문제 발생 시 후속 조치

예를 들어 `order_id` 중복은 주문 건수와 매출의 중복 집계로 이어질 수 있으므로,
중복 허용 기준을 0건으로 두고 실제 탐지 결과를 확인했습니다.

전체 결과는 `control_matrix.csv`에서 관리합니다.

## 실행 방법

Python과 pandas가 설치된 환경에서 프로젝트 폴더를 엽니다.

pandas가 설치되어 있지 않다면 다음 명령어로 설치합니다.

```bash
pip install pandas
```

원본 CSV 파일과 Python 파일이 있는 프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python dq_check.py
```

실행하면 데이터 품질 검사 결과가 터미널에 출력되고,
5개의 품질 검사 결과 CSV 파일이 생성됩니다.

생성된 결과 데이터를 Tableau에서 활용하여 품질 상태를 시각화할 수 있습니다.
